# Classic cburnett chess pieces

Artwork by **Colin M. L. Burnett**, distributed under the GNU General Public
License, version 2 or (at your option) any later version. See [LICENSE.txt](LICENSE.txt).

These are the classic cburnett SVG pieces used by Lichess. The twelve SVG files
are the editable source artwork; their drawing data has not been changed. Line
endings follow this project's CRLF convention.

- [Author](https://en.wikipedia.org/wiki/User:Cburnett)
- [Lichess attribution and license](https://github.com/lichess-org/lila/blob/master/COPYING.md)
- [Exact source revision](https://github.com/lichess-org/lila/tree/5b44d719ec5913dd62aa965f4b8d21e60a00c2c1/public/piece/cburnett)

The app loads these assets locally and does not contact Lichess during play.
